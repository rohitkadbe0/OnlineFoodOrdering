### Online Food Ordering System | Spring Boot Microservices

**Technologies:** Java, Spring Boot, Spring Cloud, Spring Security, JWT, Apache Kafka, MySQL, OpenFeign, REST APIs, Maven

- Developed a microservices-based Online Food Ordering System with separate services for users, food, orders, and delivery.
- Implemented RESTful APIs for food management, order placement, and order tracking.
- Integrated Spring Cloud OpenFeign for inter-service communication and Eureka Service Discovery with API Gateway for service routing.
- Implemented JWT-based authentication and role-based authorization for customers, restaurant owners, delivery partners, and administrators.
- Integrated Apache Kafka for asynchronous order event communication and automatic delivery assignment when orders are ready for pickup.
- Used MySQL and Spring Data JPA for database management and order information handling.
- Implemented order status tracking and Cash on Delivery workflow.
